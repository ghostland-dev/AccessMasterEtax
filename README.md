# Access Master E-Tax

Web app and REST API for producing and tracking energy tax (CSPE/TICGN) files.

## Features

- Laravel web application and REST API
- Customer, meter and tax-file management
- Data model documented in the repository

## Tech Stack

- Laravel (Blade)
- PHP
